## Decisions worth remembering

- **`chat:<uuid>` scope convention.** New conversations created on the Chat page use `chat:<uuid>` as their scope string. The backend treats it identically to `global` (no listing context). The conversation rail surfaces `chat:*` + `global` scopes; listing scopes are excluded (each listing's chat tab is its own workspace).
- **No conversation-metadata table.** Conversations are derived on read — title from first user message, last_at from `MAX(created_at)`. We accepted that titles will look ugly when the first user message is one word ("hi"), but the cost of a separate `conversation` table isn't justified yet.
- **Brand-new chats don't appear in the rail until they have a turn.** A UUID generated by `+ New chat` is "active but not yet listed." The conversation crystallizes on first message. If this feels weird in practice we can flip it.
- **Chat page uses viewport math; other pages don't.** `h-[calc(100vh-4rem)]` is on the chat page outer div specifically. The chat panel needs a height ceiling for `flex-1 + overflow-y-auto` to scroll instead of grow; other pages are happy with body scroll. We considered making `<main>` fixed-height + overflow-hidden but that would break tall pages.
- **Listings → one-column rows.** User feedback: the 3-col grid was truncating everything and felt cramped. The new row gives each listing enough vertical space to show all four financial stats and the full decision-journal quote without truncation.
- **Inter + Fraunces** for the type system. Previously the page was actually rendering in the OS default sans (the Geist variable was on `html` but `--font-sans` resolved circularly to itself in `@theme inline`). Inter as body / Fraunces as headings ships a deliberately editorial feel without going traditional. Base-layer rule applies the serif globally to `h1`/`h2`/`h3`; pages can opt out with `font-sans` on a specific heading.
- **HBR Thinking Strategically scope rejection.** The Operator corpus is narrowly scoped to acquisition mechanics per `docs/agents/agent-topology.md`. General management strategy was a clean miss. The `corpus-curator` agent flagged it instead of silently adding an inventory row — that's the right behavior to preserve.
