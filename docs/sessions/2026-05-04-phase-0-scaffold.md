## Deviations / things to know

1. **`docs/agents/agent-topology.md`** — the actual filename. The charter (§10) and CLAUDE.md reference `topology.md`. Minor inconsistency; not worth a rename now but flag if it bites later.
2. **Next.js 16 instead of 15.** `pnpm create next-app` installed 16.2.4. Charter §8 says "Next.js 15" but reads as a placeholder for "current Next." Treating this as fine without a `charter:` commit. Notable Next 16 changes already absorbed: dynamic route `params` is a `Promise<{...}>`, Turbopack is default for build.
3. **Frontend has its own `CLAUDE.md` + `AGENTS.md`** — auto-generated by Next 16 to brief AI agents on its breaking changes. Useful, kept in tree.
4. **Backend `Dockerfile` runs uvicorn with `--reload`** — appropriate for local dev compose; flag for prod hardening if/when it matters.
5. **No `alembic upgrade head` run yet** — DB doesn't exist until `docker compose up` succeeds. First boot will need it; runtime instructions land in Phase 1.
